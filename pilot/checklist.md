# SCKG Pilot Checklist

## Phase 1: Baseline (Week 1)
- [ ] Select 3 test repos (small, medium, large)
- [ ] Measure build time for each
- [ ] Measure query time for 10 common queries
- [ ] Record baseline metrics

## Phase 2: Comparison (Week 2)
- [ ] Compare graph vs grep for same queries
- [ ] Measure developer satisfaction (survey)
- [ ] Test with real developer tasks

## Phase 3: Decision (Week 3)
- [ ] Compile results
- [ ] Write decision document
- [ ] Present to team

## Success Criteria
- [ ] Build time < 10s for 1000 files
- [ ] Query speedup > 5x vs grep
- [ ] Developer satisfaction > 4/5
