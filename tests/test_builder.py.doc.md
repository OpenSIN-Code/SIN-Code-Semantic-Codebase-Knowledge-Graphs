# test_builder.py

Tests for `GraphBuilder`.

## Coverage

- Empty repo
- Single / multi-file repos
- Excluded directories
- Syntax error skipping
- Circular imports
- Class inheritance
- Large repo (100 files)
- Async functions
- Import extraction
- Call extraction
- Custom exclude sets
- Nested module paths

## Notes

Uses `tmp_path` pytest fixture for filesystem isolation.
